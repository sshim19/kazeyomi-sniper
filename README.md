# 風読みスナイパー

風と距離を読んで、的の中心をねらうゲームです。同じ日は、だれが遊んでも同じ5発に挑戦します。携帯は横向きで遊びます。

## 遊び方

1. 画面を横向きにして、「ねらう」を押します。制限時間はありません。
2. 左の指で照準を動かし、右のボタンで打ちます。マウスなら、左をドラッグしてねらい、右のボタンまたはスペースで打ちます。
3. 旗や草のなびきと、距離を見て、風の分だけずらしてねらいます。的の中心に近いほど高い点になります。
4. 5発の合計が得点です。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
